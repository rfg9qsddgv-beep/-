# 紫微斗数排盘

基于 iztro 引擎的紫微斗数在线排盘工具，支持术语解释、命盘解读与运限分析。

## 功能

- 阳历/农历输入，支持全国省市区真太阳时校正
- 十二宫命盘展示，支持点击高亮三方四正
- 大限运程、流年流月详解
- 新手模式与专业模式切换
- 术语词典搜索
- 多流派支持（中州派/三合派戊干四化切换、闰月处理、子时换日规则）

## 使用

直接在浏览器中打开 `紫微斗数.html` 即可使用，无需安装任何依赖。

## 许可
